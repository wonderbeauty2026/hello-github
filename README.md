建立时间：2026-10-09

## 以后改文件、传到 GitHub 的三步

```bash
git add -A                     # 1. 把改动收进待提交清单
git commit -m "这次改了什么"    # 2. 生成一条提交记录
git push                       # 3. 上传到 GitHub
```

打开这个文件随便改一行，再走一遍上面三步，然后刷新 GitHub 页面就能看到变化。
